## The unifying theme: invisible controls and silent encodings

One failure class dominated both releases, found over and over by the same field test (Ron using
his own app) and killed by the same rule — **a control or meaning nobody can perceive doesn't
exist**:

| Instance | Disguise |
|---|---|
| Ownership select styled as a badge | control dressed as display (its designer concluded "not editable") |
| Ctrl+Z consumed silently in the dialog | dead key wearing a shortcut's name |
| This-folder/Everywhere scope toggle | six quiet pixels its own designer forgot within 3 weeks, while the preview DISPLAYED the books it would unlock |
| "Reset to Amazon" via flag-clear (proposed, rejected) | two invisible actions, nothing visibly happens |
| Persistent author alias (proposed, rejected) | stored rule firing invisibly, no surface to see or delete it |
| Origin caption only on strays | a caption's ABSENCE as secret encoding |
| Folder picker capped at 12 behind a scrollbar | list that looks scrollable but secretly truncates |
| Index nav appearing at 50% scroll | primary navigation hidden from the entry page |
| Nav dropping the current page | layout lurching with hidden cause |
| Preview order = selection order | accidental input state shaping layout |

**The distilled law (PRINCIPLES-worthy): state and controls must be perceivable at the point of
effect; absence, position, and silence are not communication channels.** Enforcement: the
sole-user field test keeps catching these within minutes — at launch, that instrument disappears;
the law is what remains.

## ✅ What worked well

1. **Design-doc-before-code, three times** (OWNERSHIP-MODEL, UNDO-MODEL, AUTO-ORGANIZE-UNIFIED):
   each captured a multi-round design argument the same day it happened, then implementation
   proceeded against a reviewed text. Zero relitigating; several Ron-corrections (instant-visible
   Reset, fenced undo, alias rejection) recorded WITH their reasoning.
2. **Soak-as-test-rig at full speed**: 9 unified-AO alphas in 2 days, every one shaped by Ron's
   live folder-dissolution work within minutes of shipping. The doc called the soak "the test
   rig"; it outperformed the claim.
3. **Release-early discipline** (Ron-driven): item 10 shipped standalone as 7.7.2 rather than
   waiting inside a batch; 7.8.0 shipped before the batch finished; branch-per-task kept each
   alpha chain about one thing.
4. **The scope-narrowing catch became a mechanism**: "toasts EVERYWHERE" silently became
   undo-toasts-only; Ron caught it a day later by re-asking. Root cause (frame capture,
   feasibility-shaped listening, no decomposition ritual) → CLAUDE.md rule + memory tripwire
   (universal quantifiers) + the doc now records the split honestly. Applied successfully hours
   later: 7.9.0's two deferred items (Inbox File-under target, shift-click visual order) were
   named OUT LOUD in TODO before release.
5. **Mechanical audits over spot fixes**: the alpha.5 toast-label pass initially fixed only the
   site Ron hit; a script then walked every recordAction and found 4 more. Same lesson as ever
   (enumerate the class) — but this time the auditor script is the enforcement.
6. **First user contact handled without data handling**: no "send me your backup" (privacy);
   instead a Power Query recipe (key fact: book ids = ASINs) + the CSV-export feature filed.
   The user's "I doubt you'd have any interest" framing → data liberation IS the doctrine.
7. **The security-page lie died in minutes**: found during a styling question, hotfixed to prod
   ahead of everything else on Ron's IMMEDIATE call — including mid-flight branch surgery
   (stash → main → fix → push → rebase → pop) executed cleanly while Ron was actively testing
   the working tree.

## ❌ What went wrong

1. **The scope narrowing itself** (above) — silent descope of an explicit "everywhere."
   Mechanism now in place; watch it fire.
2. **7.7.1's grouped layout broke selection-order correspondence** (shift-click ranges vs visual
   order) — a rendering change made without checking what consumed the old order. Residual half
   still deferred (explicitly, this time).
3. **My alpha.1 unified rendering shipped a state ambiguity** (kept-copy vs unselected, 4 covers
   of 3 books) that Ron misread within one session — caught fast, but the one-cover-per-book
   §7 design existed in the doc and I built the per-source rendering anyway because the old
   machinery made it easy. Feasibility-shaped listening's implementation cousin.
4. **security.html had lied for months** ("not uploaded to any cloud service", "expires in 10
   days") — stale since 7.0 rebuilt sync. No mechanism existed to sweep satellite pages when
   architecture changes. Partial fix: the release checklist's Coming-Soon realignment now has a
   sibling concern — copy that DESCRIBES the architecture must be audited when the architecture
   moves (USER-GUIDE rewrite + FAQ should absorb this).
5. **PowerShell transport traps bit again** (BOM via Set-Content at 7.7.1; embedded quotes in
   commit messages twice; python-heredoc mangling for README) — every instance caught before
   damage, all now recorded in the mechanical-honesty memory. The Edit tool remains the law.
