# Post-Mortem: 7.10.0 — Save Spreadsheet (CSV), requested yesterday

**Date**: 2026-09-09
**Release**: 7.10.0, prod+dev — File → Save Spreadsheet (CSV)…, the library flattened for Excel
with the joins done app-side (tags on books; Folders as full paths and Book Lists reverse-joined
by book id). RW's first field-requested feature: asked 2026-09-08 by user #2 ("I doubt you'd have
any interest"), shipped 2026-09-09. One alpha, one release, ~90 lines.

## ✅ What worked well

1. **Request → next-day ship**, without corner-cutting: design questions were argued and settled
   BEFORE release (submenu rejected — two items don't earn a hover-hop; label = purpose-first
   honesty "Save Spreadsheet (CSV)…"; Open-With affordance rejected because the browser sandbox
   genuinely cannot launch local apps — code-expert answer killed the UX question cleanly).
2. **Doctrine did the design**: Save/Restore terminology (no "Export" anywhere), picker-first
   save flow with honest cancel + receipt toast (the 7.6.2 backup lesson reused verbatim),
   promises updated in the same commit (spreadsheet moved Coming Soon → Recent Features on both
   sync'd files — public promises track reality).
3. **The user's actual pain drove the columns**: "tags or lists is the tricky bit" → tags,
   folder paths, and Book Lists are first-class columns; the reverse-join is exactly the part
   that's miserable in Power Query (and the interim recipe — book ids = ASINs — was still
   provided rather than making him wait).
4. **No data ever changed hands**: the privacy-correct answer to "help me with my export" is a
   feature, never "send me your backup."

## ❌ What went wrong (one skirmish, instructive)

1. **The BOM lived briefly in source as an invisible literal character** — written by me, via my
   own edit strings, and my first scripted fix was silently no-op'd when the tool transport
   de-escaped `\\u` → `\u` (mechanical-honesty rule 2, verbatim, biting its own enforcer). The
   mandated temp+atomic+ASSERT pattern caught the no-op — the file was never damaged — and a
   backslash-free chr()-built script landed the explicit escape. The rules earned their keep
   against their author; the episode is the best argument yet for never relaxing them.
2. **Honest gap**: Excel-render acceptance was implicit, not explicit — Ron exercised the save
   flow (his download opened in VSC, proving file creation + content plausibility) but a
   cell-by-cell Excel check (quoting survival, BOM effect on ™/em-dash) wasn't reported before
   release. Small feature, low risk, but the checklist said "open in Excel" and the release rode
   without that line confirmed. Watch item, not incident.
