# Post-mortem — v7.17.1 (2026-09-28)

**Share… carries the full recommendation.** Released prod+dev (squash `4c09799`, tag `v7.17.1`,
branch `fix/share-content` KEPT). A small, focused patch — the first **side-fix** taken off `main`
while the `feature/overlay-system` migration is mid-flight.

## What shipped

`getShareData` built a *separate, terse* web-share payload (`webShareTitle`/`webShareText`) distinct
from the rich `emailSubject`/`emailBody`. So **Share…** (`navigator.share` → OS share sheet) sent only
a one-line snippet + link, while **Email a Friend** sent the full recommendation. Fix: the web-share
fields now reuse `emailSubject`/`emailBody` (extracted to consts, single + multi book); `webShareUrl`
set to `null` so the link isn't duplicated (it's already in the body). One chokepoint fixes every
Share… entry point; Email a Friend unchanged.

## What went right

- **The side-fix workflow worked exactly as designed.** Off `main` → `fix/share-content` → alpha →
  release → squash+tag → push. Divergence pre-flight confirmed prod==dev==main (7.17.0) before the
  push; clean fast-forwards. Next: `git merge main` into `feature/overlay-system` (trivial — the fix
  region, `getShareData`, is untouched by the overlay work; only the `ORGANIZER_VERSION` line
  reconciles, keeping 7.18.0-alpha.x).
- **Scoped honestly.** Discovered mid-test that the win is the *body*: Gmail ignores `navigator.share`
  `title`, so the OS share sheet can't set a Gmail subject no matter what — the reliable subject path
  stays Email a Friend → Open in Gmail (web). Said so plainly rather than implying a subject fix, and
  kept that platform nuance out of the user-facing CHANGELOG.

## Process notes

- **A Windows-side rabbit hole avoided.** Ron's Windows 11 share sheet stopped showing Gmail (now the
  unconfigured built-in Outlook). That's an OS-level target-registration thing RW can't control
  (`navigator.share` can't reorder or extend the sheet). Named the boundary, pointed at the in-app
  reliable Gmail path, and did **not** chase Windows configuration — out of RW's scope.
- **Context-loss caught by asking.** Ron stepped away to another project and momentarily thought the
  release was the (invisible) dialog migration. A quick "two separate tracks" clarification resolved
  it before anything shipped wrong — cheaper than assuming.
