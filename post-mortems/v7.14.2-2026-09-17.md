# Post-Mortem: 7.14.2 — the stopgap, and the day the gate went live

**Date**: 2026-09-17
**Release**: 7.14.2 (app), prod+dev — first release under the new **squash-merge + tag + keep-branch** workflow. A small code delta (dialog-dismissal stopgap) wrapped in a large *process* day: a working pre-build gate, a git-workflow change, and the resumption of release tagging.

The code shipped is minor — fix one Esc orphan, fence three modals. The reason this PM exists is everything *around* it: the recurring "new dialog forgot the fence" scar finally got a structural answer, and the collaboration itself got new machinery.

## What shipped
- **Orphan fix:** `autoOrgPreview`'s Esc branch hand-rolled a partial state clear that stranded `autoOrgSrcPopup`/`autoOrgFileUnder`; now delegates to `closeAutoOrgPreview()`.
- **3 modals fenced:** `restoreConfirm` (destructive), `newFolderHiddenAlert`, `corruptionRecovery` added to `anyDialogOpen` + `handleModalEsc` + deps; backdrop added to the two that lacked it.
- **Deferred (filed):** the overlay primitive (`<Dialog>`/`<Popover>` registry, own branch) and new-folder discard-on-cancel (~7.14.3).

## ✅ What worked well

1. **The gate works — proven on my own edits.** A `PreToolUse` hook now denies the first app-source edit of a turn with a pre-build checklist; a `Stop` hook arms it per turn. It fired twice this turn (the orphan fix, then the version drop), exactly as designed. This is the structural answer to the scar that recurred all week: enforcement moved from "remember the checklist" to "the checklist fires itself." Enforcement-by-mechanism, not discipline.
2. **The comb, done right, beat the comb done by eye.** Running the actual two-pivot state-grep found a *fifth* broken overlay (`autoOrgSrcPopup`) that the from-memory pass missed — and a live Esc-orphan bug. The mechanical pivot is the rule; "I looked" is not.
3. **The split held.** Stopgap now (live harm gone, minutes to test) + primitive later (the class, own branch). Resisting the urge to gold-plate the patch — the 6 no-Esc menus and latent drift were *deliberately* left for the rework, named and filed, not silently dropped.
4. **Ron's process insights, banked.** "A rule you don't follow every time is worthless" → the gate. "You can't predict a side fix, so always branch" → the workflow. "Legal states, not loose flags; illegal combos unrepresentable; a new flag fails open" → the sharper state-design gate. Each became a concrete mechanism, not a note.
5. **Workflow upgraded coherently:** always-branch → squash-merge one delta to main → tag `vX.Y.Z` → keep the branch as the alpha archive. Tagging resumed (lapsed after v6.4.0; v7.14.0/.1/.2 now tagged). First run executed cleanly.

## ❌ What went wrong / friction

1. **The hook first littered the repo root.** The runtime doesn't pass `scratchpad_dir`, so the flag fell back to `cwd` and a `gate-pending-*.flag` landed in the project root. Fixed by making both scripts use a deterministic system-temp path keyed by `session_id`. Lesson: a hook's file I/O must never default into the working tree.
2. **The gate fires on trivial edits too.** Version-stamp bumps tripped it this turn — working as built, but pure overhead on non-structural edits. It's the known "one denied+retried edit per turn" cost. Watch whether it grates; if so, exempt version-line-only diffs. No action yet — needs real-use data.
3. **`.claude/` is entirely gitignored**, so the tooling (command, hooks, shared settings) can't be committed without a narrow un-ignore exception — deferred until the gate is proven in daily use, then commit `commands/` + `hooks/` + move the hook config from `settings.local.json` (ignored) into the committed `settings.json` so a fresh clone actually activates it.

## 👀 Watch

- **The overlay primitive:** the real fix for the whole class; own branch, incremental, one family per alpha. Design of record in `DIALOG-DISMISSAL-AUDIT.md`.
- **New-folder discard-on-cancel (~7.14.3):** small, unrelated, Option A (delete + "New folder discarded" toast); Option C (warn-before-create) deferred.

## Final thought
The pattern of the week was: an audit fixes today's instances, a rule names the class, and only a *mechanism* stops the class from recurring. This release is the first where the mechanism is real — a gate that fires on me whether I remember it or not — and it proved itself the same day by stopping my own first edit cold. The code was a footnote; the machinery is the story.
