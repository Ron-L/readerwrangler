## What went right

- **Ron remembered the design that should govern the change.** While discussing statistics labels he asked "shouldn't
  we use the dev flag instead of localhost?" — the flag was designed (Oct 6) but never built. Building it first turned a
  statistics tweak into a real fix (self-hosters on the dev relay) and gave the relay work a trustworthy "am I dev?".
- **Re-combed instead of trusting the week-old site list** — the Oct 6 line numbers were four releases stale; two
  pivots (host checks; consumers of their results) agreed on 15 spots + 8 events, published before any edit.
- **Verified before asserting**: GoatCounter's own script (fetched) skips local addresses unless `allow_local` — so
  page views needed no change; only the hand-built events did.
- **"Testing traffic" built ON `isContributor()`** (`isContributor() || isDevSite()`), not a second implementation —
  Ron's question made that explicit.
- **The danger in the test plan was named before testing**: flipping the flag off in the regular window reconnects to
  the production relay with real credentials → test "off" only in a private window. Ron then turned that hazard into a
  feature request ("Send to Production…"), filed with a design that makes the sync deliberate and one-directional.

## What went wrong

- **Wrong name for a third-party service** ("Cloudflare's standard counting script" — it's GoatCounter's), corrected
  in the next message. Small, but exactly the "say it as fact without checking" class.
- **Vague test-step wording again**: "your normal window" — Ron asked which. Name the actual thing ("your regular
  browser window on localhost:8000").
- A sed that didn't match (escaped `\n` in a JS string) — caught by the verify grep, redone with the Edit tool.
