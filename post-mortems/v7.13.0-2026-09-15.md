## What this tiny release is data about

1. **Frustration → convention → feature in one conversation.** Ron named a recurring
   annoyance (linked title fights selection), cited a convention he'd just seen in the wild
   (Resend's DNS copy chips), and the UX discussion did the rest — including discovering the
   right *cross-view* answer was extending the June "Copy Title" menu precedent (Copy Author)
   rather than decorating grid rows. Usage remains the requirements pipeline.
2. **Doctrine paid rent twice.** Ron's "doesn't a toast imply undo?" probe forced the undo
   doctrine into one clean line — **toasts promise truth, not reversibility** — now in KB §13.
   And the grid-rows-are-objects convention justified leaving line view alone with reasons
   instead of resignation.
3. **Release scoping self-corrected.** Claude proposed patch-numbering a feature (7.12.1) and
   muddled whether work existed; Ron caught both (semver rule: features = minor). The branch
   opened as the transactional-dialog vehicle but its first alpha was self-contained — Ron's
   call to ship it standalone kept the next release's diff clean, at the cost of a fourth
   renumbering (cheap, and now a running joke).
4. **Release-sweep hygiene compounding**: this sweep caught batch item 11 still sitting in
   TODO despite shipping in 7.11.0 — a miss by THAT release's sweep. Each release's checklist
   now audits its predecessors' bookkeeping for free.
5. **Silent-toast archaeology**: Copy Title had no receipt — a pre-item-11 relic found only
   because new code landed beside it. Receipts-everywhere is a ratchet: neighbors get fixed
   when touched.
