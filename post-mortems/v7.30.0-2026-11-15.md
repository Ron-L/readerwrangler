## What shipped

1. **The one table** (`gestureTable.js`) answers every move, copy, paste and drag of today's keys, menus and drops; one
   keyboard listener; one book placement with an exact Ctrl+Z (books already there stay; each book back in its old
   place). `moveItems` and `reparentFolder` are gone. Every sentence a person sees about a move lives in the table.
2. **A gesture done as something other than its verb is said in amber, at both ends** — a copy out of the Trash
   restores; a Cut that can't be a move is done as a copy (folders or the Inbox onto a Book List, the Inbox anywhere, and

3. **Warnings look like warnings**, app-wide (amber, ~4 s) — the logger always told the app the level; the hookup
   dropped it.
4. **Series position 0** — one shared reading for every sort and display, desktop and phone; Auto-Organize follows it;
   the fetchers keep a Book 0 (tested offline with made-up records; titles numbered up to 9999).
5. **F2 renames a folder selected in the Folders view.**

## What went right

1. **Measuring every cell before building** (CELL-001–058, each asserting the decided behavior, "differs today" marked
   with the measured words): 45 of 58 cells differed, and the measurement found what the design hadn't listed — a
   Ctrl+Z after a move or copy took books out of a folder they were already in, and a copy pasted back then undone left
   a book in NO folder. Those are the first two real causes of the long-watched "books in no folder" mystery.
2. **The "differs today" mark** made test-first work at the scale of a matrix: a cell fails with its measured words or
   it's a real failure; a cell that starts passing fails until its mark is dropped; a release run refuses any mark left.
3. **Ron's verdicts turned into structure:** "the same thing everywhere" became a table that derives every cut-to-copy
   cell (TABLE-029/033 fail if one is missed); "standardize the notice" became one helper deciding when a receipt is a
   warning.
4. **Ron's "narrow, then wide"** — each try runs its own tests, the full tiers once per alpha — written into TESTING.md
   and every brief; the cell file also went 259 s → 140 s without weakening a check.
5. **"Simulate it"** (Ron) — the fetcher's parsing lifted out so a test feeds it made-up Amazon records; the one thing
   only Amazon can answer (is a position text or a number?) is counted on Ron's next normal update.

## What went wrong

1. **A private commit landed in the PUBLIC repo** (the 11-14 relay rows, on the local feature/one-table branch) — the
   command meant for `.private` ran in the outer folder. Never pushed; dropped at Ron's word. Since then every private
   commit names its repository (`git -C <path>`). The cause of the wrong folder was never pinned down — which is why the
   fix is a mechanism, not care.
2. **Delivery gaps against the task's words, found by me, not by Ron — but late:** item 17 ("books and folders: both,
   for every gesture") was missed by the menus; three left-pane folder drops stayed outside the table; F2's harmful cell
   was filed instead of fixed by the release agent. Each brief named the task; none listed the task's own numbered
   harmful cells as a checklist. The lesson (the same as sprint 3's): **a brief carries the task's own list, item by
   item, and the review checks each off.**
3. **An agent went around the pre-build gate** with `sed` for version stamps. Briefs since say "every edit through the
   Edit tool".
4. **Three one-time test failures in two days** (Reset's reload, a Diagnostics start-up, a console network-buffer error)
   — each passed alone and on a clean rerun; filed in Watching. Machine load is part of the test environment now.

## The bug no test would have caught

The undo damage above: no test ever did a move where a book was already in the destination and then pressed Ctrl+Z.
The cell file now does it for every gesture.
