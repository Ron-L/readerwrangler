# Post-mortem — v7.20.0 (2026-10-13)

**A new Tools menu.** Released prod+dev (squash `00baaec`, tag `v7.20.0`, branch `feature/tools-menu` KEPT). 2 alphas,
one afternoon — the "quick win" Ron picked to restart with, from the 2026-09-28 TODO.

## What shipped

File = your data in/out (Data Status, Import from Relay, **Relay Setup**, Restore/Save Backup, Save Spreadsheet);
View = display; **Tools** (new) = Auto-Organize, Removed books | Manage Tags, Tag from Collections | Reset App. Every
tooltip/help/doc path to a moved item updated. Under the hood: one `MenuBarItem`/`MenuDivider`/`menuAction` for all 20
items (net −165 lines), `openTagFromCollections()` out of the menu.

## What went right

- **Honest scoping of "quick, right?"** Checked before answering: the code was quick; the real work was the menu-path
  mentions (16 in the app, ~20 in docs). Saying so up front set the right expectation.
- **Ron's UX corrections beat the TODO's plan twice.** The 09-28 TODO put Relay Setup in Tools ("really config");
  Ron: File is in/out *to the relay* too. Keeping Setup beside Import also keeps the disabled Import's tooltip
  ("File > Relay Setup") true. And "Library" vs "File": more accurate, worse — menu names work by recognition.
- **Three pivots, each finding what the last missed.** Menu name + item; every arrow style (→, >, ›, `&rsaquo;`,
  `&rarr;`); bold-formatted paths (`File → **Tag from Collections…**`). The `›` tooltip and two bold KB paths would have
  shipped stale with two pivots. Law 5's "two independent pivots" is a floor, not a ceiling, for prose.
- **Boundary-asserting scripts for markup moves.** Both block moves (the menu split; the 20-item rewrite) were done by
  a script that first asserts the text at every boundary line, then splices — zero hand-cut braces, parse-clean first
  time, both runs.
- **The gate paid for itself:** item 6 ("less code?") surfaced the menu-item duplication; Ron said "now"; −165 lines.

## What went wrong

- **Shell edits still skip the gate** (the open 7.19.0 TODO): the release-prep version stamps went in via `sed`. Harmless
  here (stamps only, approved), but it's the same tool gap — the TODO stands.
- Nothing user-visible; both alphas passed first time.
